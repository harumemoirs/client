# Haru Memoirs - Frontend

Haru Memoirs is a seasonal memoir blog inspired by the Japanese concept of "Haru" (Spring). It features a visually rich, contemplative interface for sharing stories, poetry, and letters, designed with a premium, serene user experience.

## Quick Start

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

1.  Clone the repository:
    ```bash
    git clone <repository-url>
    cd haru-memoirs-frontend
    ```

2.  Install dependencies:
    ```bash
    npm install
    # or
    yarn install
    ```

3.  Run the development server:
    ```bash
    npm run dev
    # or
    yarn dev
    ```

4.  Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

-   `src/app`: Application routes and pages (App Router).
-   `src/components`: Reusable React components.
-   `src/ui`: UI-specific components.
-   `src/lib`: Core logic and utilities (e.g., like system, browser ID).
-   `src/functions/services`: API service layers for fetching data.
-   `src/seo`: SEO configurations and metadata generation.
-   `public`: Static assets (images, fonts, etc.).
